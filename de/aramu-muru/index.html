Aramu Muru (Hayu Marca)

Ein perfektes Tor, etwa sieben Meter im Quadrat, in eine rote Felswand gehauen, ohne einen Raum dahinter.

Nahe dem Titicacasee ist Hayu Marca, das 'Tor der Götter', eine glatte Nische mit einer kleinen T-förmigen Vertiefung am Fuß wie ein Schlüsselloch. Eine beliebte Geschichte erzählt von einem Priester namens Aramu Muru, der mit einer goldenen Scheibe hindurchging. Bekannt wurde der Ort Anfang der 1990er-Jahre.

Aber... wer hat es gehauen, und wann? Keine archäologische Studie hat es datiert; Forscher halten einen unvollendeten Inka-Schrein für eine plausible Erklärung, während manche Enthusiasten fragen, ob es ein 'Sternentor' ist, eine Behauptung ohne archäologische Grundlage.
